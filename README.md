 I built an Active Directory home lab incorporating Splunk, Kali Linux, Sysmon, and Atomic Red Team. 
 The setup simulates a real-world environment where attacks occur, and events are monitored through a SIEM. 
 I built and configured a comprehensive Active Directory home lab using VMware to simulate a real-world enterprise environment. 
 This environment included multiple virtual machines running Windows, Kali Linux, and various monitoring tools such as Splunk and Sysmon. 
 To simulate a cyberattack, I launched a brute force attack from a Kali Linux machine targeting a Windows computer within the network. 
 I used Splunk's SIEM capabilities to detect and analyze the attack in real-time, identifying the source and specific events tied to the attack. 
 After identifying the attack's origin, I leveraged Atomic Red Team's scripts to implement mitigations and strengthen security controls. 
 The lab setup provided valuable hands-on experience in real-time attack detection, investigation, and remediation in an enterprise environment.
